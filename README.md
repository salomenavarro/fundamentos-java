# Actividad: Fundamentos de Programación en Java

Este proyecto es una implementación práctica de los conceptos esenciales del lenguaje Java. Está estructurado de forma modular, donde cada clase aborda un tema específico mediante métodos estáticos que demuestran la sintaxis, el comportamiento y las mejores prácticas del lenguaje.

## Tabla de Contenidos

El proyecto cubre los siguientes temas fundamentales:

1.  **Variables y Constantes**: Declaración, asignación, convenciones de nombres (camelCase) y uso de `final`.
2.  **Tipos de Datos Primitivos**: Manejo de enteros, flotantes, caracteres y booleanos.
3.  **Conversión de Tipos**: Casting implícito (widening) y explícito (narrowing).
4.  **Operadores**: Aritméticos, relacionales, lógicos, de asignación compuesta y el operador ternario.
5.  **Entrada de Datos**: Uso de la clase `Scanner` y manejo del buffer de entrada.
6.  **Estructuras Condicionales**: Uso de `if`, `else if`, `else` y estructuras `switch`.
7.  **Estructuras de Repetición**: Bucles `while`, `do-while`, `for` clásico y control de bucles con `break` y `continue`.
8.  **Métodos Estáticos**: Declaración, paso de parámetros, retorno de valores y sobrecarga.
9.  **Arreglos Unidimensionales**: Inicialización y recorrido con `for-each`.
10. **Arreglos Bidimensionales**: Gestión de matrices y bucles anidados.
11. **Manipulación de Cadenas**: Métodos de la clase `String`, inmutabilidad y `StringBuilder`.
12. **Manejo de Excepciones**: Bloques `try-catch-finally` y prevención de errores en tiempo de ejecución.

## Instrucciones de Ejecución

### Requisitos previos
* Tener instalado el **JDK (Java Development Kit)** versión 11 o superior.
* Un terminal o consola de comandos.



### Compilación
Para compilar todas las clases del proyecto, sitúate en la carpeta raíz y ejecuta:

    javac src/main/java/com/example/*.java -d target/classes

### Ejecución

    java -cp target/classes com.example.Main
